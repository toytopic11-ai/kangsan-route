# 회무노트: 대의원 회무자료 관리 앱 (시작 안내서)

갤럭시 탭 S8(S펜), 폰, PC에서 쓰는 **나만의 회무자료 서재**입니다.
중앙회, 경북도회, 포항시회 자료를 대·중·소 분류로 정리하고, PDF에 S펜으로 필기하며, AI로 검색·작성합니다.

## 폴더 구성

| 경로 | 내용 | 상태 |
|---|---|---|
| `supabase/schema.sql` | DB 전체(테이블 25개, 보안 규칙, 검색·자동기록 함수, 기본 분류) | ✅ PostgreSQL 16에서 실행·재실행·보안 테스트 통과 |
| `supabase/functions/hoemu-ai/index.ts` | AI 서버 함수 1개로 모든 AI 기능 처리(질문, 작성, 글자 인식, 예산 추출, 조문 분해, 리허설, 주간 리포트, 법령 확인) | ✅ SDK 타입 검사 통과, 버전 고정 |
| `src/ink/` | **S펜 필기 엔진** + 도구막대(React) | ✅ 자동 테스트 통과(펜, 형광펜, 직선, 지우개, 실행취소, 손가락 차단, 저장/복원) |
| `demo/pen-demo.html` | 필기 체험 페이지(파일 하나, 인터넷 없이 동작) | 탭 S8 크롬에서 바로 열어 보기 |
| `LOVABLE_PROMPTS.md` | Lovable 단계별 지시문 0~25단계 | 체크박스로 진행 관리 |

## 1. 준비 (Lovable 크레딧 0)

1. **Supabase**(supabase.com) 무료 프로젝트 생성 (지역: Northeast Asia (Seoul))
2. Supabase → **SQL Editor** → `supabase/schema.sql` 전체를 붙여 넣고 **Run**
   - 여러 번 실행해도 안전합니다.
3. Supabase → **Authentication → Users → Add user**로 본인 계정 1개 생성
   - 생성 후 **Sign In / Providers**에서 *Allow new users to sign up*을 **끄기** (외부인 가입 차단)
4. Supabase → **Edge Functions → Deploy a new function**(브라우저 편집기)
   - 이름: `hoemu-ai`
   - 내용: `supabase/functions/hoemu-ai/index.ts` 붙여넣기 → Deploy
5. Supabase → **Edge Functions → Secrets**
   - `ANTHROPIC_API_KEY`: console.anthropic.com에서 발급. 발급 화면에서 **월 사용 한도(예: $5)**도 함께 설정하세요.
   - (선택) `LAW_API_OC`: 국가법령정보센터 Open API(open.law.go.kr) 신청 후 받은 OC 값

## 2. Lovable 연결

1. Lovable 새 프로젝트 → **Supabase 연결**(1번에서 만든 외부 프로젝트 선택)
   - Lovable Cloud를 따로 켜지 마세요.
2. **GitHub 연결** → 생성된 저장소에 `src/ink/` 폴더 4개 파일을 업로드
   - 방법: GitHub 웹 → *Add file → Upload files*. Lovable에 자동 반영되며 크레딧이 들지 않습니다.
3. `LOVABLE_PROMPTS.md`의 **0단계**부터 순서대로 진행

> 💡 Lovable 저장소 이름을 Claude Code에 알려 주시면 2번 업로드와 어려운 단계(필기 연결, PWA, 공유 저장)를 직접 처리해 크레딧을 더 아낄 수 있습니다.

## 3. 비용 (월 기준, 개인 사용)

| 항목 | 요금제 | 예상 비용 |
|---|---|---|
| Lovable | 무료 플랜(하루 크레딧 범위에서 하루 1~2단계씩) 또는 개발하는 1개월만 유료 | 0원~1개월 구독료 |
| Supabase | Free: DB 500MB, 파일 1GB | 0원 |
| 앱 호스팅 | Lovable 게시 또는 Netlify 무료 | 0원 |
| Claude API | Haiku 5.5(입력 $0.10, 출력 $0.50 / 100만 토큰), effort `low` | 질문 1회 약 3원 → **월 1,000원 이하** 예상 |
| 법령 API | 국가법령정보센터 | 0원 |

**비용을 지키는 장치(이미 코드에 들어 있음)**
- AI 월 상한: 기본 $3. 상한에 도달하면 서버가 AI 호출을 자동으로 차단하며, 설정 화면에서 조정할 수 있습니다.
- 근거 페이지는 최대 8개, 페이지당 2,500자만 AI에 보냅니다.
- 주간 리포트는 주 1회만 생성하고, 이후에는 저장본을 다시 보여 줍니다.
- 법령 확인은 하루 1회만 실제로 조회합니다.
- 예약 서버 작업이 없습니다. 앱을 열 때 확인하므로 추가 서버 비용이 없습니다.
- 사진은 1600px·JPEG 80%로 줄여서 저장하고 글자 인식에 보냅니다.

**무료 플랜 주의**
- Supabase 무료 프로젝트는 **7일간 접속이 없으면 일시정지**됩니다. 매일 쓰시면 문제없고, 정지되면 대시보드에서 *Restore*를 누르면 됩니다.
- 파일 1GB 한도: 설정 화면의 저장공간 표시를 보며, 큰 스캔 PDF는 원본을 MYBOX에 보관하는 것을 권장합니다.

## 4. S펜 필기 엔진 특징 (`src/ink`)

| 기능 | 구현 방식 |
|---|---|
| 부드러운 선 | perfect-freehand 필압 외곽선 + 2차 곡선, 중간 좌표 누락 방지(coalesced events), 예측 좌표로 지연 감소, 저지연 캔버스 |
| 굵기 | 펜 1~16 / 형광펜 8~40 / 지우개 6~60. 빠른 선택 3단계(가늘게·보통·굵게) + 슬라이더 + 실제 선 미리보기 |
| 필압 | S펜 압력 반영, 필압 민감도 조절. 마우스·손가락은 속도로 굵기 표현 |
| 손떨림 보정 | 0~0.9 조절 |
| 색상 | 펜 6색 + 형광펜 5색 + 사용자 지정 색 |
| 즐겨찾기 펜 | 최대 8개. 한 번 탭으로 전환, `＋`로 현재 펜 저장, 길게 눌러 삭제 |
| 형광펜 | 곱하기 합성으로 글자가 그대로 비치고, 겹쳐 칠해도 진해지지 않음. 펜 글씨 아래에 깔림 |
| 직선 | 직선 도구, 또는 긋고 0.55초 멈추면 자동 직선(±4° 이내면 수평/수직 고정, 진동 피드백) |
| 지우개 | 획 단위. **S펜 버튼을 누른 채 문지르면 지우개** |
| 손바닥 방지 | S펜만 필기. 손가락 1개는 관성 스크롤, 2개는 확대 |
| 호버 | S펜을 화면에 가까이 대면 굵기 크기 원 표시 |
| 실행취소 | 최대 200단계 |
| 좌표 | 페이지 가로폭 1000 기준이라 확대·축소와 폰·탭·PC 간에 위치가 정확히 유지됨 |
| 저장 | 페이지당 JSON 1행. 원본 PDF는 수정하지 않음 |

### 수정 방법
- 기본 색·굵기: `src/ink/penSettings.ts`의 `PEN_COLORS`, `PEN_SIZE_STEPS`
- 직선 보정 대기 시간: `src/ink/inkEngine.ts`의 `HOLD_MS`
- 필압 곡선: `strokeOutline()`의 `easing`
